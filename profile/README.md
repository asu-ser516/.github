# SER 516 — Software Enterprise: Project and Process Management

**Arizona State University**

This GitHub organization preserves student project repositories from multiple
offerings of SER 516 — Software Enterprise: Project and Process Management.

## Course Offerings

### Spring 2018

Projects from the Spring 2018 offering include individual and team repositories
for Projects One through Four, along with selected extra-credit projects.

Repository names use the prefix:

`2018-`

### Spring 2019

Projects from the Spring 2019 offering include Project One, Project Two, and
nine team repositories for Project Three.

Repository names use the prefix:

`2019-`

### Spring 2020

Projects from the Spring 2020 offering include Projects One through Five.

Repository names use the prefix:

`2020-`

## Repository Naming

Historical repositories follow the convention:

`YEAR-ProjectName[-TeamXX]`

Examples:

- `2018-ProjectTwo-Team01`
- `2019-ProjectThree-Team04`
- `2020-ProjectFive`
